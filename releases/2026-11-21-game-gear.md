`tests/headless_gg.py` が生成するゲームギアの ROM は、毎フレーム VBlank を待ってパッドと Start のポートを記録し、背景色を赤と青で交互に替える。
新規プロファイルで 2 回実行し、次の結果が一致した。

| 確認 | 結果 |
|---|---|
| 入力 | 15 フレーム目のボタン 1 が 6 番目の記録（`$EF`）、17 フレーム目の Start が 8 番目の記録だけに出る |
| フレーム | 22 フレーム目の終わりで ROM の数えたフレームが 12。VDP の開始走査線を固定する前は実行ごとに 11 と 12 に分かれた |
| RAM | 書き込んでいない work RAM が 0 |
| 画面 | 連続する 2 フレームが 160×144 の単色（赤、青）。前フレームとの合成がない |
